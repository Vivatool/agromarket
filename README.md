# АгроМаркет

Навчальний інтернет-магазин фермерських продуктів для практики ручного тестування (курс Manual QA).

- Сайт: https://vivatool.github.io/agromarket/
- Специфікація вимог і тестові акаунти: https://vivatool.github.io/agromarket/docs/specification.html

Сайт працює повністю в браузері: акаунти, кошик і замовлення зберігаються в localStorage.
Скинути дані можна кнопкою на сторінці специфікації.
